# Scenario Lab

Scenario-based React, Next.js, JavaScript, TypeScript, frontend architecture, security, performance, testing, accessibility, and system design interview preparation across industries.

## Read online

The study site is published at:

https://harshadhindlekar.github.io/scenario-based-questions/

## What is included

- All-sector guide covering 22 product and industry contexts.
- Banking and security deep dive.
- Complete Q&amp;A covering the core technical, coding, DSA, behavioral, sector-scenario, security, and system-design prompts.
- Beginner-to-advanced core questions, scenario prompts, answer patterns, resources, and a 30-day practice plan.
- Searchable GitHub Pages reader in `docs/`.

The source guides are available directly as [`docs/all-sector-react-next-interview-prep.md`](docs/all-sector-react-next-interview-prep.md), [`docs/react-next-banking-interview-prep.md`](docs/react-next-banking-interview-prep.md), [`docs/core-answer-bank.md`](docs/core-answer-bank.md), and [`docs/scenario-answers.md`](docs/scenario-answers.md).
